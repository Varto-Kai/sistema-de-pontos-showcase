# Aviso de Código Proprietário & Política de Acesso

Este repositório é um **Estudo de Caso de Engenharia & Portfólio Técnico Público** do sistema **Kairós**.

## 🔒 Propriedade Intelectual & Código Fechado

O código-fonte integral de produção, esquemas de infraestrutura em nuvem, regras corporativas de integração de folha de pagamento e credenciais do projeto são de **natureza proprietária e protegida** (conforme a Lei de Software nº 9.609/1998 e políticas de segurança da informação).

Para demonstrar a competência técnica sem violar o sigilo comercial, este repositório disponibiliza:
1. **Especificações de arquitetura** e Decisões de Design (ADRs);
2. **Amostra executável e higienizada** do motor puro de cálculo trabalhista (`samples/`);
3. **Metodologia da esteira de desenvolvimento assistido por IA**;
4. **Capturas de tela e evidências visuais de funcionamento**.

---

## 🤝 Solicitação de Acesso Técnico & Code Walkthrough

Se você é **recrutador técnico, gestor de engenharia ou avaliador em processo seletivo**, terei o maior prazer em apresentar o projeto em profundidade através de:

- **Live Code Walkthrough (Recomendado):** Uma chamada de 20 minutos onde compartilho minha tela e explico a estrutura concêntrica de Clean Architecture, gerenciamento de estado no React 19, e suítes de testes automatizados;
- **Acesso Temporário de Leitura (Read-Only):** Concessão de acesso como colaborador no repositório privado para inspeção assíncrona de código.
